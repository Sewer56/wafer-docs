## Connection Details

Use your Wafer Pass API key with these values:

|                              |                                          |
| ---------------------------- | ---------------------------------------- |
| **OpenAI-compatible endpoint** | `https://pass.wafer.ai/v1`             |
| **Anthropic-compatible endpoint** | `https://pass.wafer.ai/v1/messages` |
| **Authentication**           | API key                                  |

See [**Models**](#models) below for the `model` strings to pass on the OpenAI-compatible endpoint.

<Note>
  Claude Code and Conductor use the Anthropic Messages endpoint — see
  [Set Up Claude Code](/wafer-pass/claude-code) or
  [Set Up Conductor](/wafer-pass/conductor). All other harnesses use the
  OpenAI-compatible endpoint above.
</Note>

For harnesses not listed at the top of this page, copy these OpenAI-compatible settings:

* **Base URL**: `https://pass.wafer.ai/v1`
* **Model**: `Qwen3.5-397B-A17B` or `GLM-5.1`
* **Compatibility mode**: OpenAI-compatible / OpenAI API

```json
{
  "baseUrl": "https://pass.wafer.ai/v1",
  "apiKey": "YOUR_WAFER_API_KEY",
  "model": "Qwen3.5-397B-A17B"
}
```

If the harness asks for a provider name, label it `Wafer`. If it asks whether your key is a
bearer token or an API key, select API key.

## Models

| `model` string           | Family                  | Max context tokens | Notes                                                             |
| ------------------------ | ----------------------- | ------------------ | ----------------------------------------------------------------- |
| `Qwen3.5-397B-A17B`      | Qwen3.5, 397B MoE       | `262144`           | Multiples faster than base SGLang on Wafer's stack                |
| `GLM-5.1`                | Z.AI flagship           | `202752`           |                                                                   |

**Max context tokens** is the hard limit — requests that exceed it return a `400`. If your harness
has a **Context Window Size** setting (Cline, Roo Code, Droid, etc.), set it to the exact value from
the table. Reserve ~2–4k tokens for the model's response.

Pass any `model` string from the table to an OpenAI-compatible harness pointed at
`https://pass.wafer.ai/v1`. Model names are **case-insensitive** (`GLM-5.1` = `glm-5.1`). An
unknown model name returns a `404` with the list of available models.
