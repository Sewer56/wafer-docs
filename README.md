# Wafer Docs

Public documentation for Wafer.

## Local Development

This is a [Mintlify] docs site. Requires [Node.js] 18+.

```bash
npx mintlify dev
```

Then open the preview URL shown in output, e.g.

```
✓ preview ready
  local   → http://localhost:3000
  network → http://192.168.1.1:3000
```

In this case, `http://localhost:3000`.

[Mintlify]: https://mintlify.com
[Node.js]: https://nodejs.org
